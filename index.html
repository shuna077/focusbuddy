아이패드로 그려도 돼요!

Focus Buddy는 화면의 움직임을 보고 시간을 재요.
그래서 아이패드 작업도 그대로 기록할 수 있어요.

  1. 미러링 프로그램으로 아이패드 화면을 컴퓨터에 띄워요.
  2. 설정 → 타이머·감지 → 바꾸기에서 그 창을 등록해요.
  3. 끝! 아이패드에서 그리는 동안만 시간이 쌓여요.
마우스 움직임까지 세고 싶지 않으면 ‘마우스 움직임도 집중으로 치기’를 꺼 두세요.

방을 친구한테 선물할 수 있어요

꾸민 방을 파일 하나로 뽑아서 보내면, 친구는 더블클릭만 하면 돼요.
직접 그린 그림으로 방을 만들 수도 있어요.

  1. 미니룸 옆 ◐ 미니룸 꾸미기 창방 목록 아래에 버튼들이 모여 있어요.
    창은 끌어서 원하는 곳에 둘 수 있어요.
  2. 선물용으로 내보내기방 이름이랑 한마디 메시지를 적으면
    .fbroom 파일이 생겨요.
  3. 친구가 더블클릭친구 Focus Buddy에 방이 쏙 들어가고 메시지가 떠요.
    카테고리에도 알아서 정리돼요.
  4. 그림으로 방 만들기가이드 그림 위에 방을 그려서 넣으면 나만의 방이 돼요.
    캐릭터 앞에 올 물건도 따로 그릴 수 있어요.
  5. 꾸미기 통째로 선물 NEW꾸미기 템플릿 → 친구에게 보낼 파일로.
    홈 · 미니룸 · 말풍선 꾸밈을 .fbstyle 하나로 줘요.

받는 법은 간단해요

  1. 아래 링크에서 zip 받기파일 이름에 버전이 붙어서 받아져요 (FocusBuddy-Setup-2.26.1.zip).
  2. 압축 풀고 설치.bat 더블클릭zip을 오른쪽 클릭 → 압축 풀기를 먼저 해 주세요.
    설치가 끝나면 바탕화면에 아이콘이 생겨요.
    폴더 안에 설치 안내, 버전 파일(Focus Buddy v2.24.txt), 기능 소개 그림도 들어 있어요.
  3. 업데이트는 버튼 하나로새 버전이 나오면 켤 때 알려 줘요.
    설정 → 일반 → 업데이트 확인을 눌러도 돼요. 내 데이터는 그대로예요.

시작하기 홈 화면과 위젯 타이머와 움직임 감지 캐릭터 미니룸과 방 방 분위기 (어둡게 · 역광) 방 파일 (받기 · 선물 · 만들기) 플래너 · 보드 · 캘린더 통계와 작업 기록 수입 관리 공유 모드 · 캡처 꾸미기 · 테마 · 색 고르기 말풍선 꾸미기 꾸미기 파일 주고받기 알림 · 소리 · 이름표 백업 · 데이터 · 업데이트 단축키 자주 묻는 질문
시작하기처음 켰을 때 이것부터

1. 내 캐릭터 넣기

홈 화면 가운데 ‘이곳을 클릭해 캐릭터를 추가해보세요!’를 눌러요. 배경이 투명한 PNG(누끼 딴 그림)를 넣으면 스티커처럼 예쁘게 떠요. 움직이는 GIF · WEBP도 돼요.

2. 배경 바꾸기

오른쪽 위 연필 버튼(꾸미기 모드) → 배경에서 내 그림으로 바꿔요. 그림을 고르면 홈 화면에 보일 부분을 네모로 고를 수 있고, 그림에서 뽑은 색으로 테마가 저절로 맞춰져요.

3. 미니룸 띄우기

오른쪽 위 🏠 집 모양 버튼을 누르면 바탕화면에 캐릭터가 따로 떠요. 마우스를 올리고 옆의 ◐ 미니룸 꾸미기 버튼을 누르면 작은 도트 방을 고를 수 있어요.

4. 예시 일정 정리하기

[예시]로 시작하는 일정과 할 일은 눌러서 고치거나 지워도 돼요.

타이머는 따로 시작 버튼을 누르지 않아도 화면 움직임을 보고 저절로 흘러가요.

예전에 쓰던 컴퓨터가 있다면: 처음 켤 때 백업 파일을 찾아서 “이전 백업에서 불러올까요?” 하고 물어봐요.

홈 화면과 위젯시계 · 캘린더 · 타이머 · 디데이 · 할 일 · 음악 · 스티커

위젯

  • 시계 · 캘린더: 오늘 날짜와 이번 달. 일정 있는 날엔 점이 찍혀요. 시계는 왼쪽 · 가운데 · 오른쪽으로 정렬할 수 있어요.
  • 집중 타이머: 오늘 작업한 시간과 하루 목표까지 남은 시간.
  • 디데이: 마감이 가까운 일정과 체크리스트 진행도.
  • 오늘의 할 일: 바로 적고 체크해요.
  • 음악: 스포티파이, 유튜브, 멜론 등 지금 재생 중인 곡을 띄우고, 재생 · 일시정지 · 다음 곡도 돼요.
  • 앱 독 · 바로가기: 자주 쓰는 프로그램, 폴더, 사이트를 붙여 둬요.
  • 인사말 · 프로필 · 세로 문구 · 사진 · 메모 · 주간 통계: 필요한 것만 켜서 써요. 프로필 사진은 동그라미로 자르고 확대 · 축소해요.

홈 캐릭터 말풍선

설정 → 말풍선 → ‘홈에서도 말풍선 쌓기’를 켜면 디데이 말풍선이 캐릭터 머리 위에 차곡차곡 쌓여요.

스티커

  • 꾸미기 모드 → 스티커 추가. 끌어서 옮기고, 모서리 동그라미로 크기, 휠로 회전해요.
  • GIF · 움직이는 WEBP 스티커는 움직여요.
  • 오른쪽 클릭 → 모양 자르기: 둥근 모서리 · 원 · 하트 · 별 · 구름. 테두리와 그림자가 모양을 따라가요.
  • 여러 개를 골라 테두리 · 그림자 · 모양을 한 번에 바꿀 수 있어요.

순서와 레이어

  • 위젯 · 스티커 · 캐릭터가 모두 한 줄 순서예요. 소품 스티커를 캐릭터 뒤에도 둘 수 있어요.
  • 고르면 옆에 맨 앞 · 앞 · 뒤 · 맨 뒤 · 작게 · 크게 버튼이 떠요.
  • 꾸미기 모드 위쪽 ‘레이어’를 누르면 한 목록으로 보여요. 끌어서 순서 바꾸기, 눈으로 숨기기, 휴지통으로 지우기.
  • 스티커와 캐릭터는 그림이 있는 곳만 눌려요. 투명한 곳을 누르면 아래에 있는 게 잡혀요.
타이머와 움직임 감지켜 두기만 하면 작업 시간이 쌓여요

화면이 움직이는 동안은 ‘집중 중’, 한동안 그대로면 ‘쉬는 중’으로 바뀌어요. 멍하니 있던 시간은 빠져요.

무엇을 볼지 고르기

  • 전체 화면: 기본값. 모니터 전체의 움직임을 봐요.
  • 특정 창: 그림 프로그램 창만 봐요. 딴짓한 시간은 안 쌓여요. 여러 창을 체크할 수 있고, 그중 하나라도 움직이면 작업 중이에요 (최대 8개)NEW
  • 화면 영역: 화면 일부분만 네모로 골라요.

아이패드로 그릴 때

미러링 프로그램으로 아이패드 화면을 컴퓨터에 띄우고, 설정 → 타이머·감지 → 바꾸기에서 그 창을 등록하면 끝이에요. 마우스 움직임까지 세고 싶지 않으면 ‘마우스 움직임도 집중으로 치기’를 꺼 두세요.

그 밖의 설정

  • 감지 민감도: 가만히 있을 때 막대가 기준선을 넘지 않게 맞춰요.
  • 쉬는 중으로 바뀌기까지: 몇 초 동안 움직임이 없으면 쉬는 걸로 볼지.
  • 하루 목표: 정해 두면 인사말에 남은 시간이 나와요.
  • 휴식 알림: 오래 쉬지 않으면 캐릭터가 쉬자고 말해 줘요.
  • 일시정지: 타이머 위젯 버튼이나 단축키 Ctrl+Alt+P.

전체 화면 감지는 화면을 작게 줄여서 찍고, 마우스가 움직이는 동안엔 찍지 않아서 가벼워요 (2.25). 그래도 끊기면 ‘특정 창’으로 그림 프로그램만 골라 보세요.

캐릭터캐릭터 그림 · 상태별 표정 · 테두리
  • 캐릭터 그림: 홈 화면 가운데를 누르거나 설정 → 캐릭터에서 바꿔요. PNG · GIF · WEBP 모두 돼요.
  • 상태별 표정: ‘집중 중’, ‘쉬는 중’처럼 상태마다 다른 그림을 넣을 수 있어요.
  • 테두리 · 그림자: 스티커처럼 테두리를 두르고 두께 · 색을 바꿔요.
  • 창마다 다른 캐릭터: 미니룸 · 공유 창은 홈과 같은 캐릭터를 쓰거나 따로 정할 수 있어요.
  • 미니룸의 캐릭터를 누르면 통통 · 말랑 · 흔들 애니메이션이 나와요.
미니룸과 방방 고르기 · 여러 캐릭터 · 위치 옮기기 · 카테고리

미니룸은 내 캐릭터가 사는 작은 방이에요 (예전 이름: 캐릭터 창). 홈 화면 오른쪽 위 🏠 집 버튼으로 켜고 꺼요. 마우스를 올리면 옆에 버튼이, 오른쪽 클릭하면 모든 메뉴가 나와요.

시간 배지 · 음악 카드

  • 캐릭터 아래 시간 배지와 음악 카드를 끌어서 원하는 곳에 둬요 (Alt 누르고 끌면 자석 끄기).
  • 크기는 설정 → 미니룸 → 시간 배지 · 음악 카드에서 60~250%. 오른쪽 클릭 → 시간 · 음악 → 위치 되돌리기.

오른쪽 클릭 메뉴

맨 위 내 상태, 그 아래 방 · 캐릭터 · 말풍선 · 시간 · 음악 묶음, 그리고 캡처 · 홈 화면 열기 · 미니룸 설정. 설정 → 미니룸도 같은 이름으로 나뉘어 있어요.

방 켜기 / 끄기

  • 미니룸 오른쪽 클릭 → 방 켜기, 또는 미니룸 꾸미기 창 맨 위 버튼.
  • 끄면 캐릭터만 떠 있고, 그동안 배경은 투명 · 카드 · 단색 · 초록 중에 골라요. 다시 켜면 마지막 방이 돌아와요.

방 고르기

  • 미니룸 옆 ◐ 미니룸 꾸미기 버튼(또는 오른쪽 클릭 → 방 → 미니룸 꾸미기 창 열기)에서 기본 방 5개와 내 방(받은 방 · 만든 방) 중에 골라요.
  • Ctrl + 끌기로 방 위치, Ctrl + 휠로 방 크기를 바꿔요.
  • 방 그림자: 없음 · 약하게 · 진하게. 방 대신 투명 · 카드 · 단색 · 초록(OBS 크로마키) 배경도 돼요.

캐릭터 위치 옮기기

  • Shift + 끌기: 방은 화면에 그대로 두고, 캐릭터만 방 안에서 옮겨요.
  • 오른쪽 클릭 → 여러 캐릭터 · 캐릭터 위치 → ‘메인 캐릭터 위치 되돌리기’로 가운데로 돌아와요.

여러 캐릭터

  • 오른쪽 클릭 → 여러 캐릭터 · 캐릭터 위치 → 캐릭터 추가…로 다른 캐릭터를 같은 방에 세워요.
  • 배치 편집 모드를 켜면 캐릭터마다 점선이 생기고, 그냥 끌어서 옮기고 휠로 크기를 바꿔요.
  • 같이 띄운 캐릭터를 오른쪽 클릭 → 크게 · 작게 · 원래 크기 · 좌우 뒤집기 · 메인 캐릭터 앞에 두기 · 그림 바꾸기 · 빼기.
  • 테두리와 방 분위기(어둡게 · 역광)는 메인 캐릭터와 똑같이 입혀지고, 꾸미기 템플릿에도 같이 저장돼요.

내 방 카테고리NEW

  • 자동 분류: 받은 방은 알아서 카테고리로 들어가요. ‘고딕 성당 · 하얀 성당’은 ‘고딕 성당’ 칸에 ‘하얀 성당’으로. 알 수 없는 방은 ‘받은 방’에 모여요. 받은 방은 어느 칸에 있어도 방 이름만 짧게 보여요. 넣을 때 뜨는 창에서 카테고리를 바꿀 수도 있어요.
  • 예전에 넣은 방도 한 번 정리: 2.25로 처음 켜면 ‘분류 없음’에 있던 받은 방들을 같은 규칙으로 한 번 정리해요. 직접 옮겨 둔 방은 그대로예요.
  • 끌어서 옮기기: 방을 다른 카테고리 이름이나 빈칸에 놓으면 옮겨지고, 방 사이에 놓으면 순서가 바뀌어요. 카테고리 이름도 끌어서 순서를 바꿔요.
  • 미니룸 꾸미기 창의 ＋ 카테고리로 묶음을 만들어요 (예: 고딕, 바이오하자드, 친구한테 받은 방). 이미 있는 이름으로 바꾸면 두 칸이 합쳐져요.
  • 방을 오른쪽 클릭 → 카테고리 옮기기. 카테고리 이름을 누르면 접었다 펴져요.
  • 카테고리 이름을 오른쪽 클릭 → 이름 바꾸기 · 위로 · 아래로 · 지우기 · 만든 사람 이름으로 자동 묶기.
  • 미니룸 오른쪽 클릭 → 배경 메뉴와 설정의 방 목록에도 카테고리별로 보여요.

미니룸 꾸미기 창 크기NEW

  • 창 테두리(네 면 · 모서리)를 끌어서 크게 · 작게. 넓히면 한 줄에 방이 더 많이 보여요.
  • 내 방 목록 아래 ⋯ 손잡이를 끌면 목록이 길어지고, 화면보다 길어지면 창 전체가 스크롤돼요. 두 번 클릭하면 원래대로.

말풍선과 창 설정

  • 디데이 · 내 상태 · 대사가 말풍선으로 떠요. 말풍선은 끌어서 자리를 옮기고, 꼬리 방향도 골라요. 모양은 ‘말풍선 꾸미기’에서.
  • 항상 위 · 클릭 통과(눌러도 뒤 창이 눌림) · OBS 창 캡처에 보이게 (목록 이름: ‘Focus Buddy 미니룸’).
  • 마우스 휠로 캐릭터 크기를 바꿔요.
방 분위기 (어둡게 · 역광)어두운 방에서도 캐릭터가 자연스럽게

어두운 방에 밝은 캐릭터가 붕 떠 보일 때 써요. 방마다 따로 기억해서, 방을 바꾸면 그 방의 설정으로 바뀌어요.

  • 캐릭터 어둡게: 0~80%. 색은 ‘자동’이면 방의 밤 색, 직접 고를 수도 있어요.
  • 역광 방향: 없음 · 왼쪽 · 오른쪽 · 위 · 뒤(전체). ‘뒤’는 윤곽 전체가 빛나고 바깥으로도 살짝 번져요.
  • 강도 0~100% · 두께 1~10 · 색 촛불 · 달빛 · 새벽 · 형광 · 직접 고르기.

미니룸 꾸미기 창 아래쪽, 또는 미니룸 오른쪽 클릭 → 방 분위기에서 바꿔요.

방 파일 (받기 · 선물 · 만들기).fbroom 파일 하나로 주고받아요
  • 받은 방 넣기: 방 파일을 더블클릭하거나, 미니룸에 끌어다 놓거나, ‘방 파일 불러오기’를 눌러요. 보낸 사람의 메시지가 떠요.
  • 선물하기: 미니룸 꾸미기 창 → 선물용으로 내보내기. 방 이름 · 카테고리 · 한마디를 적으면 파일이 생겨요. 받는 사람 미니룸에서도 그 카테고리로 묶여요.
  • 그림으로 방 만들기: 가이드 그림 위에 방을 그려서 넣으면 나만의 방이 돼요. 캐릭터 앞에 올 물건은 앞 그림으로 따로 넣어요.

새 부품을 쓰는 방은 최신 버전에서만 열려요. 안 열리면 업데이트를 먼저 해 주세요.

플래너 · 보드 · 캘린더외주 · 커미션 마감 관리

플래너

  • 프로젝트를 만들고 시작일 · 마감일을 정해요. 오늘 · 내일 · 고른 날부터 몇 주 · 몇 달 뒤로 바로 계산해요.
  • 러프 → 선화 → 밑색 → 완성처럼 단계를 체크하면 진행도가 올라가요. 자주 쓰는 단계는 템플릿으로 저장해요.
  • 진행이 늦은 일정은 ‘마감 위험’으로 따로 보여 주고, 캐릭터가 하루 한 번 알려 줘요.
  • ‘디데이에 표시’ · ‘캐릭터 말풍선’을 켜면 홈과 미니룸에도 떠요.

보드

할 일 → 진행 중 → 검토·수정 → 완료. 카드를 끌어서 옮기면 상태가 바뀌어요.

캘린더

월 · 주 · 목록으로 봐요. 구글 캘린더 주소를 넣으면 원래 쓰던 일정도 같이 보여요. 분류(외주, 커미션…)의 이름과 색은 연필 버튼으로 바꿔요.

통계와 작업 기록얼마나, 무엇을 그렸는지
  • 오늘 · 최근 7일 · 최근 30일 · 하루 평균 작업 시간.
  • 분류별 · 프로젝트별 작업 시간 막대.
  • 작업 기록: 집중한 시간은 저절로 쌓이고, 두 번 눌러 그날 컨디션과 메모를 남겨요. 컨디션 흐름도 그래프로 봐요.
  • 잠깐 쉬었다 와도 한 덩어리로 묶이게 ‘작업 기록 나누는 기준’을 설정 → 일반에서 바꿔요.
수입 관리커미션 · 고객 · 지출 · 가격표 · 메시지
  • 개요: 이번 달 실수령 · 미수금 · 지출 · 순이익과 최근 12개월 그래프. 연도별로 바꾸면 한 해 합계와 해마다 비교.
  • 커미션: 작업마다 금액, 받은 돈, 마감. 슬롯으로 이번 달 받을 수 있는 수를 정해요.
  • 고객: 고객별로 작업과 받은 돈을 모아 봐요.
  • 지출: 구독료, 재료비 같은 지출.
  • 가격표 · 견적: 내 가격표로 견적을 빨리 계산해요.
  • 메시지: 견적 안내 · 입금 확인 · 러프 전달 문구에 고객 이름 · 작업 · 금액이 자동으로 채워져요.
  • 환율: 달러 · 위안 · 엔화로 받은 돈도 원화로 합쳐 보여 줘요.
  • 금액 가리기: 버튼 하나로 ₩•••로 가려요. 공유 창을 켜면 저절로 가려지게 할 수도 있어요.
공유 모드 · 캡처방송용 창과 자랑용 캡처

공유 모드

  • 캐릭터 · 타이머 · 디데이가 뜨는 방송용 창이에요. OBS ‘윈도우 캡처’로 잡으면 방송 화면에 올라가요.
  • 옆 바로가기: 공유 창 옆에 자주 쓰는 앱 바로가기를 붙여요. 왼쪽 · 오른쪽, 마우스를 올릴 때만 보이기도 골라요.
  • 캐릭터 옮기기NEW: Alt 를 누른 채 캐릭터를 끌면 위아래 · 좌우로 자유롭게. 설정 → 공유 모드에서 좌우 · 위아래 위치도 맞춰요.

캡처

  • 오른쪽 위 카메라 버튼: 다운로드 › FocusBuddy 캡처 폴더에 저장하고 클립보드에도 복사해요.
  • 카메라 버튼 오른쪽 클릭 → 찍을 범위: 홈 화면만 · 홈 + 미니룸(화면에 놓인 그대로) · 홈 + 미니룸(소개 그림처럼 겹쳐서) · 미니룸만.
  • ‘소개 그림처럼’은 둥근 홈 화면에 그림자를 넣고, 오른쪽 아래에 미니룸을 살짝 튀어나오게 겹쳐 한 장으로 만들어요. 홈 화면 카메라 버튼 → 찍을 범위에서 골라요. 미니룸 오른쪽 클릭 → 📷 캡처는 미니룸만 바로 찍어요.
  • 말풍선 빼고 찍기 · 2배 크기로 저장(도트가 번지지 않게) · 저장 위치 바꾸기.
  • 찍고 나면 뜨는 알림의 ‘폴더 열기’로 방금 찍은 파일을 바로 확인해요.

꾸미기 모드

배경과 테마

  • 내 그림을 배경으로 쓰면 그림에서 색을 뽑아 테마가 저절로 맞춰져요. 보일 영역은 나중에 다시 고를 수 있어요.
  • GIF · 움직이는 WEBP 배경도 돼요.
  • 자동 · 다크 · 화이트, 강조색, 유리 흐림, 배경 어둡게, 글자 그림자는 설정 → 꾸미기에서.

색 고르기 창

  • 스포이드: 누르면 화면이 잠깐 멈추고, 홈 배경 · 스티커 · 미니룸 등 원하는 곳을 클릭하면 그 색을 가져와요. 돋보기로 한 칸씩 크게 보여 주고, Esc나 오른쪽 클릭으로 취소해요. 모니터가 여러 개여도 돼요.
  • 바로 미리보기: 강조색 · 테두리 색 · 단색 배경 · 역광 색 등은 슬라이더를 움직이는 동안 바로 바뀌어 보여요. [취소]하면 원래 색으로 돌아가요.
  • 최근 쓴 색 · 배경에서 뽑은 색: 눌러서 바로 골라요.

꾸미기 템플릿

  • 기본 테마 5개: 밤하늘 집중, 노을 카페, 딸기우유, 민트 스튜디오, 구름 라벤더.
  • 내 템플릿: 테마 · 배경 · 배치 · 스티커 · 캐릭터(같이 띄운 캐릭터 포함)를 슬롯에 저장하고 한 번에 불러와요.
  • 캐릭터가 저장되지 않은 예전 템플릿은 목록에 따로 표시되고, 불러올 때 알려 줘요.

🔔 알림

  • 홈 화면 오른쪽 위 🔔 버튼. 안 읽은 알림 수가 빨간 숫자로 보여요.
  • 새 버전 · 업데이트 완료 · 공지 · 안내가 모여요.
  • 📢 공지NEW: 만든 사람이 올린 새 소식 · 이벤트가 몇 시간 안에 알림으로 와요. 누르면 전체 내용과 링크를 볼 수 있어요. 공지만 끄려면 설정 → 일반 → 알림 · 소리에서 ‘공지’를 꺼요.

  • 설정 → 일반 → 백업 파일 만들기: 일정 · 수입 · 커미션 · 템플릿 · 꾸미기 · 넣은 그림이 zip 하나에 전부 들어가요.
  • zip은 압축을 풀지 말고 그대로 보관해요. 되돌릴 땐 백업에서 되돌리기에서 그 zip을 그대로 골라요.
  • 내 그림 폴더: zip 안에 배경 · 캐릭터 · 표정 · 스티커 · 방 · 기타로 이름 붙여 한 번 더 모아 둬요. 그림만 꺼내 쓰고 싶을 때 열어 보세요.
  • 새 컴퓨터에서: 설치하고 처음 켜면 바탕화면 · 다운로드 · 문서에서 백업 파일을 찾아 [이 백업 불러오기] · [백업 파일 직접 고르기] · [새로 시작] 중에 고르게 해 줘요.
  • 업데이트할 때는 최근 설정 백업을 자동으로 남겨 둬요.

업데이트

  • 설정 → 일반 → 업데이트 확인. 새 버전이 나오면 바뀐 내용이 카드로 정리된 창이 뜨고 🔔 알림에도 남아요 (켜 둔 채로도 6시간마다 확인). 내 데이터는 그대로예요.
  • 새 버전이 제대로 안 켜지면 이전 버전으로 알아서 돌아가요.
  • 새 버전으로 처음 켜면 업데이트 소식 창(핵심 3가지 · 바로 가 보기 · 지난 업데이트 모아 보기)이 한 번 뜨고, 바뀐 버튼은 둘러보기로 짚어 줘요.

오류가 났어요

오류 창의 ‘만든 사람에게 보내기’를 눌러 주세요. 보내기 전에 내용을 보여 주고, 일정 · 수입 · 그림은 보내지 않아요. 사용자 이름과 폴더 경로는 가려져요.

오류 창은 안 떴는데 뭔가 이상해요NEW

🐞 버그 제보하기로 알려 주세요. 설정 → 일반, 작업 표시줄 아이콘 메뉴, 미니룸 · 공유 창 오른쪽 클릭 메뉴에 있어요. 어떤 문제인지 · 어디서 생겼는지 고르고 한 줄만 적으면 돼요. Win+Shift+S로 잘라 둔 화면을 붙여 넣거나 Focus Buddy 창만 찍어서 사진도 같이 보낼 수 있어요.

바탕화면 아이콘으로 안 켜져요

‘애플리케이션 제어 정책에서 이 파일을 차단했습니다’가 뜨면 설치 폴더의 설치.bat으로 한 번 켠 뒤 설정 → 일반 → 바로가기 다시 만들기를 눌러 주세요. 작업 표시줄에 고정해 둔 아이콘도 같이 고쳐져요.

타이머가 안 흘러요

설정 → 타이머·감지에서 감지 대상을 확인해 주세요. ‘특정 창’이면 그 창이 최소화돼 있지 않은지, 일시정지 중은 아닌지 봐 주세요.

미니룸을 눌러도 반응이 없어요

‘클릭 통과’가 켜져 있으면 눌리지 않아요. 설정 → 미니룸에서 꺼 주세요.

업데이트하면 설정이 사라지나요?

아니요. 일정 · 수입 · 꾸미기는 그대로이고, 업데이트 전에 자동 백업도 해 둬요.

컴퓨터가 느려진 것 같아요

설정 → 일반 → 저사양 모드를 켜 보세요. 미니룸의 숨쉬기 · 반짝이를 꺼도 가벼워져요.
